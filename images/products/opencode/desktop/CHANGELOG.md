# Changelog

OpenCode Desktop versions independently of the substrate. Its published image
version includes both versions because the image embeds both, and the
substrate version is also recorded on the image itself.

## [0.1.0]

- Pin OpenCode 1.18.10 and open its terminal interface in the persistent
  workspace without installing the separate OpenCode desktop application.
- Preserve credentials, configuration, state, sessions, and downloaded tools
  below `/home/agent/.opencode` across restarts.
- Apply opencode.ai's `#1B1818` terminal surface, `#131010` desktop chrome,
  `#F2EDED` text, `#FDFFCC` accent, and square mark across the browser landing
  page, OpenCode TUI, wallpaper, toolbar, window decorations, and Launcher
  artwork while preserving explicit user theme choices.
